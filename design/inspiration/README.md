# Design inspiration

Put your inspiration screenshots in this folder. Use short, clear names:

- `01-landing-calm.png`
- `02-workspace-layout.png`
- `03-buttons-and-cards.png`

Rules:
- Screenshots are for reference only. Do not copy them into the app.
- Do not copy logos, illustrations, photos, or text from other products.
- Take ideas (spacing, layout, colour mood, hierarchy), then write them in `docs/DESIGN.md`.
- Kilo reads `docs/DESIGN.md` and `design/tokens.json`. It may not read images reliably, so the written notes are what matters.
